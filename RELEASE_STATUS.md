# Release scope

Version 0.1.0. James C. Simmonds approved publishing this isolated checker under MIT on 2 October 2026. LICENSE covers the files in this repository. The full MIRANDA and ASTERION platforms retain their existing rights and restrictions.

The checker, tests and numerical fixture export were prepared with AI assistance. The 40 fixtures derive from existing ASTERION records; original source hashes and scope are recorded in PROVENANCE.json. No NASA/PVS code, resume, correspondence, credentials or fleet records are included.

No novel or patentable method is asserted. This is a small engineering utility based on established mathematics. Outside human review, demonstrated adoption and comparative evaluation remain pending. It is not a formally verified Python implementation.

The earlier private review ZIP is preserved separately. Its source code was retained except that replay.py now ignores Git metadata so a normal clone can be checked. Public files are normalized to UTF-8 with LF line endings. Documentation and licensing were updated for this release.
